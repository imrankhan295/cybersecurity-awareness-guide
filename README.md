**Task:** Cybersecurity Awareness

## Objective

Create a practical cybersecurity awareness guide (2 to 3 pages) for university students and early-career staff. The guide covers phishing, social engineering, suspicious links and attachments, impersonation, urgency tactics and safe reporting, using realistic but fictional examples.

## Approach

1. Read public guidance from CISA, UK NCSC, US FTC, the Indian Cyber Crime Portal and CERT-In.
2. List the most common attack types and warning signs.
3. Write three fictional scenarios with the correct response for each.
4. Add a "what to do if you clicked" checklist and reporting steps.
5. Review the guide for clarity and length.

AI assistance (Claude) was used to help draft and structure the content. I reviewed and edited the final text.
